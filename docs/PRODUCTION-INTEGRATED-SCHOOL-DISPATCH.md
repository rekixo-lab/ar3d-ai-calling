# Integrated production School calling and CRM import mapping

This batch implements a current-MFA Super Admin bulk calling authorization for up to 50 exact reviewed School jobs, shared funding admission, durable one-use dispatch claim, server-owned School session creation, existing Plivo POST adapter, signed callback recovery, bounded automatic settlement and terminal capacity release, tenant result read API, dashboard controls and privacy inventory. Funding-only approval and old prepared jobs never dial. The deployment does not enable the new AR3D_INDUSTRY_SCHOOL_DISPATCH_ENABLED variable or change provider credentials. Existing School voice, funding, provider disclosure and automatic CDR settlement approvals are also required. Recovery is considered with new dispatch disabled. Unknown POSTs are never retried or assumed free; expired funded releases that provably never POSTed and definite rejected sessions with no carrier identifiers can release an exact unused hold. Ambiguous funding admissions remain locked for review. The existing minute trigger alternates bounded industry work with property work, rotating funding, dialing and recovery. This conserves D1 queries; it is not a high-throughput or real-carrier acceptance claim.

CSV/XLSX imports support bounded header inspection and explicit index mapping to existing allowlisted CRM contact fields; automatic header aliases remain compatible. Preview and commit use the exact map. Import never grants consent or financial-account authorization. School results show accepted bounded answers and verified billed/connected seconds, no raw transcript or provider monetary cost.

Finance, Banking and Insurance remain non-callable drafts, because simulation is not identity verification or an authorized account data source. Appointment-specific announcement runtime is not yet implemented. Fresh review/re-preparation after an already completed immutable job remains conservatively blocked. Migration 0030 is additive and guarded. Synthetic automated fixtures only; no staging, live customer calls, paid TTS or real wallet operations. Merge only after exact-head CI.
