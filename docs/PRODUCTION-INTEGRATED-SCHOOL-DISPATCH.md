Preview and commit use the exact map. Import never grants consent or financial-account authorization. Finance, Banking and Insurance remain non-callable drafts, because simulation is not identity verification or an authorized account data source. Appointment-specific announcement runtime is not yet implemented. Fresh review/re-preparation after an already completed immutable job remains conservatively blocked. Migration 0030 is additive and guarded. Synthetic automated fixtures only; no staging, live customer calls, paid TTS or real wallet operations. Merge only after exact-head CI.
