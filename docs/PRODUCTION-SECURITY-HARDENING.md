# Production admin and legacy callback hardening

Require a current, non-revoked, unexpired MFA session and current active Super Admin role for tenant lifecycle, zero/paid-credit onboarding, legacy tenant creation and administrator-issued invitations. Bootstrap, MFA enrollment/login and client-member invitation behavior are unchanged. Existing sessions issued before enrollment must sign in again for these actions. This is session-level MFA, not per-action TOTP.

The existing signed GET format is unchanged. Reject duplicate/ambiguous parameter names/decoded delimiters and conflicting request identities; do not replace a known request UUID with a destination match. Legacy hangup evidence can be accepted for up to 24 hours after session expiry with exact identity, without restarting speech. Conditional callback writes cannot reopen an ended call. Existing commercial call enablement/disclosure switches now block legacy prompt/turn processing as well as answer, but preserve signed hangup and already-authorized keypad STOP. No carrier-side recall guarantee.

Record a bounded SHA-256 digest ledger in existing legacy session JSON before each claimed recording/STT, preventing same recording reuse across subsequent turns. In-flight pre-upgrade rows have no historical digest ledger. Existing question sequence, provider selection and settlement are preserved. No new migration, provider API operation, real call, credentials, production data edits or staging. The separate dashboard emergency stop and all-provider replay/interop verification remain future work. Automated synthetic regression checks do not establish live carrier interoperability.
