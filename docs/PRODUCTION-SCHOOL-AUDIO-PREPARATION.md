# School audio preparation (production-only, default disabled)

This adds a current-MFA Super Admin preparation action, private R2 listening and independent review for one exact previously reviewed frozen School launch. Static graph text only, up to five prompts and 2,000 UTF-16 units. No recipient input, microphone, new calls, client credit charge or automatic provider request at deployment.

The paid adapter is closed unless an explicitly separately funded Sarvam TTS account/credential and its conservative tax-inclusive INR envelope are independently reviewed and configured: AR3D_SCHOOL_TTS_ENABLED=approved, AR3D_SCHOOL_TTS_API_KEY (must differ from the call/STT key), AR3D_SCHOOL_TTS_BUDGET_MICROS (cumulative upper envelope, <=1000 INR), AR3D_SCHOOL_TTS_RATE_MICROS_PER_CHAR (reviewed upper bound in integer millionths of INR), AR3D_SCHOOL_TTS_FUNDING_REFERENCE. Distinct keys alone do not establish distinct provider accounts or separate funds. Do not enable until those facts and rate/rounding are independently verified. This is not a live balance or invoice, and no amounts are deducted from the existing calling ledger. No automatic reset or release: failed, crashed, rejected and approved attempts retain the full reservation until a separately reviewed reconciliation feature exists. A new frozen reviewed version is needed after a failed or rejected attempt. One global in-flight claim, two-minute deadline, no automatic retries.

The generation POST atomically claims the immutable budget reservation and checks current MFA, tenant and reviewed version. Each node increments the durable attempted count before the fixed Sarvam HTTP streaming POST (Bulbul v3, Shubh, 64k MP3, 22050 Hz). Bounded response, MP3 header sanity, content-addressed conditional private R2 writes and exact read-back SHA-256; no arbitrary URLs or provider error bodies. Interrupted partial assets remain private, inaccessible via review endpoints; orphan cleanup remains needed. The operator verifies all audio; a different current-MFA Super Admin approves the exact manifest digest. Playback is authenticated, not a public share. The server-only readApprovedSchoolAudioPack verifies all bytes again for a future dispatcher. No true MP3 decoding, automated comparison of spoken words, complete PII detection or real provider interoperability guarantee.

Production schema migration 0038 is additive and verifies expected columns and immutable triggers. Existing calling and WhatsApp behavior is unchanged. School outbound dispatch remains disabled. No staging, actual TTS generation, customer call or provider configuration change was performed by this PR. Official API contract: https://docs.sarvam.ai/api-reference/text-to-speech/convert-stream .
