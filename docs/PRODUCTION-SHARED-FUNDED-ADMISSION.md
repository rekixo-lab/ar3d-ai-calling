# Shared funded admission (production-only)

An explicit current-MFA Super Admin can authorize a bounded funding admission for one exact prepared School job, approved manifest, recipient review and expiry (within one hour; 90–180 seconds). The authorization is immutable and one-use. This is not permission to dial and reserves nothing by itself. The existing client queue may cancel before a claim, not after an occupied claim. A future dispatch release must be separately implemented.

The server-only claimFundedIndustryAdmission adapter checks explicit admission/voice switches, provider setup, the common emergency pause, provider faults/throttle, calling window and exact fresh audio/recipient. The atomic shared CRM claim counts both legacy property and industry occupied/uncertain records, enforcing the same global/per-company capacity and same-lead overlap guard. Legacy scheduling and dashboard counts include these records without an extra D1 query. Industry records are not passed to the property reconciliation path. The existing reserveBudgetedMinutes atomically reserves client minutes and both provider budgets for the exact job ID, including the pause predicate. Final scope recheck releases only a positively identified unused hold before any provider submission; ambiguous failures lock the claim and retain the budget. No retries, no second wallet. A funded result is explicitly not dispatchReady.

No route or cron calls the server-only claim function in this version. No real reservations, provider POSTs, calls, separate environment or configuration changes are made. Production calling cannot be enabled for School until a separate provider submission lifecycle, signed terminal evidence/results and industry CDR settlement exist. Funded/unknown records are conservatively occupied; do not manually manufacture or clear them. CRM migration 0027 is additive and verified with safety triggers. Automated local synthetic fixtures exercise both job types and exact shared wallet accounting.
